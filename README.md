# Shri Ram Khata — React + JavaScript

Professional supplier khata / ledger application converted from React + TypeScript to React + JavaScript (JSX).

## Stack
- React + JSX
- JavaScript
- Vite
- Material UI
- SCSS
- React Router
- XLSX
- localStorage

## Run
```bash
npm install
npm run dev
```

The app keeps supplier relationships by stable supplier ID, so renaming a supplier does not reset transaction balances.
